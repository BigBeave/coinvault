🚀 Free GitHub Pages Deployment (Zero Server Cost)

Because CoinVault features a complete client-side JavaScript engine (static/js/coin-engine.js), it can be hosted completely free on GitHub Pages forever:

  1. Create a repository on GitHub (e.g., coinvault).
  2. Push your code to GitHub: 
    git remote add origin https://github.com/<your-username>/coinvault.git
git branch -M main
git push -u origin main
  3. In your repository, click Settings > Pages.
  4. Under Build and deployment, set Source to Deploy from a branch, choose main branch and / (root) folder.
  5. Click Save. In about 60 seconds, your site will be live at: 
    https://<your-username>.github.io/coinvault/
Direct Mobile Gemini Vision: On your iPhone, open the app, tap ⚙️ Settings, select "⚡ Standalone iPhone Mode", and paste your free Google Gemini API key from AI Studio. Photos will be analyzed directly from your phone with no PC required!

📱 Installing on iPhone Home Screen

  1. Open your GitHub Pages URL in Safari on your iPhone.
  2. Tap the Share button (square with arrow pointing up).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add in the top right corner.

CoinVault will now run as a full-screen, native-feeling app with custom icons and offline caching.
