OVERVIEW
--------
CoinVault is a mobile-first iOS numismatic identifier and multi-platform selling
listing generator (eBay, Mercari, Whatnot, Reddit).

It runs 100% standalone inside iOS Safari / PWA on your iPhone with zero PC or
local server required, and can be hosted completely free on GitHub Pages.

This guide covers:
1. The Expanded 32-Series Global Database (Ancient Coins, World Bullion, Banknotes).
2. Standalone On-Device PWA Mode (Zero PC Required).
3. GitHub & GitHub Pages Free Hosting Setup.
4. Other 1-Click Free Cloud Hosting Options (Render, Vercel).
5. Installing on iPhone Home Screen as a Native Web App.

2. STANDALONE ON-DEVICE MODE (ZERO PC REQUIRED)
--------------------------------------------------------------------------------
CoinVault contains a complete client-side numismatic JavaScript engine
(static/js/coin-engine.js) that runs 100% inside your mobile browser:

• Direct Mobile Gemini Vision AI:
  Add your free Google Gemini API key in Settings (⚙️). iOS Safari sends photos
  directly to Google Gemini Cloud over HTTPS. Your PC is never involved!

• Instant Local Catalog & Bullion Engine:
  All 32 series specs, spot price calculations, melt values (including 0.00 melt
  for paper currency and ancient bronze), and varieties run in-memory on the phone.

• Tailored Multi-Platform Listings:
  - eBay: Enforces strict 80-character title limit with smart category tags
    ("Ancient Coin", "World Coin", "Banknote", "Old US Coin"), responsive HTML
    description, and direct pre-fill listing link.
  - Mercari: Category-matched tags and pricing.
  - Whatnot: Sudden death auction notes and livestream starting bids.
  - Reddit: Markdown table with verification photo instructions.

HOW TO ACTIVATE STANDALONE MODE ON IPHONE:
1. Tap the "⚙️" Settings button in the top right header.
2. Under "Operation Mode", select: "⚡ Standalone iPhone Mode (No PC Server Needed)".
3. Paste your free Gemini API key from https://aistudio.google.com.
4. Tap "Save Settings". The header badge will indicate "⚡ Standalone".

3. LIVE GITHUB PAGES HOSTING (100% FREE FOREVER, ZERO PC)
--------------------------------------------------------------------------------
CoinVault is designed with GitHub Pages compatibility out-of-the-box. Root-level
index.html, manifest.json, service-worker.js, and static/ directories allow the
entire PWA to be hosted as a static web app.

LIVE DEPLOYMENT STATUS:
• GitHub Repository: https://github.com/BigBeave/coinvault
• Live GitHub Pages App: https://bigbeave.github.io/coinvault/
• Branch: main (Folder: / root)
• Status: Enabled and building / active 24/7

ACCESS & SETUP ON IPHONE:
1. Open https://bigbeave.github.io/coinvault/ in Safari on your iPhone.
2. Tap Settings (⚙️) and enter your free Gemini API key from aistudio.google.com once.
3. Tap the Safari Share button -> "Add to Home Screen".
4. You now have a permanent, free, 24/7 coin identifying app on your phone!


--------------------------------------------------------------------------------
4. OTHER FREE 1-CLICK CLOUD HOSTING OPTIONS
--------------------------------------------------------------------------------
If you prefer running the full Python backend with backend API proxying:

OPTION A: Render.com (Free Python Web Service)
- Pre-configured: render.yaml & requirements.txt
- Steps:
  1. Sign in to https://render.com with GitHub.
  2. Click "New +" -> "Blueprint" and connect your coinvault repository.
  3. Render builds and launches your live Python web service automatically.

OPTION B: Vercel
- Pre-configured: vercel.json
- Steps:
  1. Sign in to https://vercel.com.
  2. Click "Add New" -> "Project" and import your repository.


--------------------------------------------------------------------------------
5. ADD TO IPHONE HOME SCREEN AS NATIVE APP
--------------------------------------------------------------------------------
1. Open CoinVault in Safari on your iPhone (either your GitHub Pages URL or Cloud URL).
2. Tap the Share icon (square with upward arrow) at the bottom toolbar.
3. Scroll down and tap "Add to Home Screen".
4. Tap "Add" in the top right corner.

Outcome:
CoinVault now appears on your home screen with its custom gold coin icon.
It opens in full-screen native app mode (without Safari URL bars or browser controls)
and caches all resources for instant launch anywhere.
